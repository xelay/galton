# 🔺 Треугольный Квинкункс

PWA-игра на основе доски Гальтона с треугольными поворотными штырьками.

## Быстрый старт

```bash
# Сервить статику (любой HTTP-сервер)
npx serve .
# или
python3 -m http.server 8080
```

Открыть `http://localhost:8080` в браузере.

## Установка на iOS

1. Открыть `https://xelay.github.io/galton/` в Safari
2. Нажать «Поделиться» → «На экран «Домой»»
3. Игра установится как PWA и работает офлайн

## Иконки

Открыть `generate-icons.html` в браузере и сохранить `icon-192.png` и `icon-512.png` в корень репозитория.

## Правила игры

- Случайно выбирается **целевая секция** (выделена красным ★)
- Поворачивайте треугольные штырьки, чтобы направить поток шариков в цель
- Нажмите **▶ Пуск** — шарики рассыпаются
- **Победа**: в целевой секции больше шариков, чем в любой другой

## Управление

| Действие | Эффект |
|---|---|
| Клик/тап по штырьку (одиночный режим) | Поворот штырька на 15° |
| Зажать и вести (пакетный режим) | Выделить прямоугольник и повернуть все внутри |
| Свайп двумя пальцами | Повернуть все штырьки в направлении свайпа |
| Долгое нажатие (600 мс) | Сбросить все повороты |
| Кнопка «Захват: ряд/столб.» | Поворот целого ряда или столбца одним тапом |

## Физика

Алгоритм «матрицы переходов»: для каждого ряда вычисляется вектор вероятностей распределения шариков по щелям. Угол поворота штырька смещает вероятность влево (CCW) или вправо. Итог — нормализованная гистограмма из 2000 шариков. Несколько «пилотных» шариков анимируются для визуализации падения.

## Стек

- Vanilla JS (ES6+), HTML5 Canvas
- Без внешних зависимостей
- PWA: manifest.json + Service Worker (cache-first)
- Совместимость: iOS Safari 14+, Chrome, Firefox
